# ClawHub Pricing

ClawHub's public registry, public read API, CLI read flows, and published SKILL.md downloads are free to use.

## Public Registry

- Price: $0
- Includes: public skill search, plugin search, skill detail pages, public SKILL.md file reads, public package metadata, and public package artifact downloads.
- Authentication: not required for public read endpoints.

## Publisher Account

- Price: $0
- Includes: publishing skills, publishing OpenClaw packages, managing owned listings, and token-authenticated CLI/API workflows.
- Authentication: ClawHub account plus API token.
- License rule: skills published on ClawHub use MIT-0. ClawHub does not support paid skills, per-skill pricing, paywalls, or revenue sharing.

## Self-Hosting

- Price: no ClawHub license fee.
- Operator costs: infrastructure, Convex, storage, email/OAuth providers, and any third-party services are paid directly by the operator.

Third-party skills or plugins can integrate with paid external services, but those costs are external to ClawHub and must be documented by the publisher.
